# Skill: Transcription Agent

## Purpose

Process raw transcripts (from calls, videos, audio notes) into structured, reusable content assets. Turn one recording into multiple outputs.

## When to use

- After a client discovery call or onboarding session
- After recording a YouTube video or podcast
- When processing a voice note or audio brain dump
- When repurposing long-form video content into shorts, captions, or articles

## Process

### 1. Clean the transcript
- Remove filler words (um, uh, you know, like) from key quotes
- Fix obvious transcription errors
- Mark speaker changes if multiple people
- Note timestamps for highlights

### 2. Extract outputs

**From a client call:**
```
CLIENT CONTEXT:
  - Company:
  - Fleet size:
  - Key pain points:
  - Current tools:
  - Agreed next step:

KEY QUOTES (direct, cleaned):
  - "[Quote]"

INSIGHTS FOR CONTENT: [Observations that could become content angles]
FOLLOW-UP ACTIONS: [What George needs to do]
```

**From a video/podcast recording:**
```
TITLE IDEAS: [3 options]
HOOK OPTIONS: [3 opening lines for Shorts/Reels]
KEY MOMENTS (with timestamps):
  - [00:00] — [What's said]
SHORTS CANDIDATES: [Timestamps of 30–60s standalone segments]
CAPTION DRAFT: [First draft for IG or LinkedIn]
ARTICLE ANGLE: [If the content can become a long-form piece]
```

**From a voice note / brain dump:**
```
CORE IDEA: [One sentence summary]
STRUCTURED OUTLINE: [Numbered points]
NEXT ACTION: [What to do with this]
```

### 3. Save to memory if relevant
If the call or recording contains context about a client or key decision, use the memory agent skill to save it.

## Tool note

Transcription itself (audio → text) is done externally (Whisper, Riverside, etc.) before this skill is invoked. This skill processes the text output.
