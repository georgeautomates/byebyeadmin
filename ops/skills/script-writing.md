# Skill: Script Writing

## Pre-Flight

Before writing: read `ops/brand-context/voice.md` (George's voice, spoken delivery rules) and `ops/brand-context/positioning.md` (what we're known for, differentiators to reference). Check `ops/learnings.md` → script-writing section for any logged corrections.

## Purpose

Write scripts for YouTube videos, YouTube Shorts, Instagram Reels, and podcast-style audio content for ByeByeAdmin's brand channels.

## Formats

### YouTube Shorts / Instagram Reels (30–60 seconds)

Structure:
1. **Hook (0–3s):** Bold claim or question. No preamble. Start mid-thought if needed.
2. **Problem (3–15s):** Name the pain. Make it specific to haulage.
3. **Reveal (15–45s):** The automation, the result, the insight. Show don't tell where possible.
4. **CTA (45–60s):** One action. Follow, comment, or link in bio.

Word count: ~100–150 words for 60s delivery.
Pace: Conversational, not presenter. Write how George actually talks.

### YouTube long-form (5–15 min)

Structure:
1. **Open loop (0–30s):** Tease the outcome before explaining the problem.
2. **Context (30s–2min):** Why this matters for haulage operators specifically.
3. **Main content:** Step-by-step or story-driven. Include real numbers where possible.
4. **Summary (last 60s):** Recap the key point. Point to next video or resource.

### Principles

- Write in first person (George's voice)
- No corporate language
- Use haulage-specific terms naturally: TMS, job sheets, PODs, tachograph, FORS, O-licence
- No em dashes
- Short punchy sentences for spoken delivery
- Add [pause] or [cut] markers for editing guidance
- Include B-roll suggestions in brackets: [screen recording of n8n workflow]
